### **Detailed Explanation of `nodes.py` and Frequency-Dependent Guidance (FDG)**

This document provides a comprehensive analysis of the `nodes.py` file, which implements a custom ComfyUI node for **Frequency-Dependent Guidance (FDG)**. The explanation covers the node's high-level purpose, the core concepts it's built upon, a detailed breakdown of each parameter, and an overview of the internal helper functions.

---

### **1. High-Level Purpose of `FDGNode`**

The `FDGNode` is designed to improve the quality of images generated by diffusion models, particularly at low "guidance scale" (CFG) values. In standard diffusion models, a higher CFG scale forces the model to adhere more strictly to the text prompt, often leading to more detailed but potentially oversaturated and artifact-ridden images. Conversely, a low CFG scale produces more creative but less prompt-adherent results.

**FDG offers a solution to this trade-off.** As the paper linked in the `readme.md` ("Guidance in the Frequency Domain Enables High-Fidelity Sampling at Low CFG Scales") suggests, FDG applies guidance differently to the various frequencies of an image. It allows for strong guidance on high-frequency details (like textures and edges) while applying weaker guidance on low-frequency components (like overall composition and color gradients).

**Practical Effect:** Using the `FDGNode` allows you to generate images that are both creative and detailed, without the typical artifacts of a high CFG scale. It gives you fine-grained control over how the model interprets your prompt, separating the guidance for fine details from the guidance for the broader structure of the image.

---

### **2. Core Concepts: Laplacian Pyramids**

The central technique used in `nodes.py` is the **Laplacian Pyramid**. This is a method for decomposing an image into a series of frequency bands.

*   **How it works:** A Laplacian pyramid is created by taking an image, blurring it, and subtracting the blurred version from the original. This difference forms the first level of the pyramid, representing the highest frequency details. The blurred image is then downscaled, and the process is repeated. This continues for a set number of `levels`. The final, smallest image is the "residual" and represents the lowest frequency information.
*   **Why it's used here:** By decomposing the model's conditional and unconditional predictions into Laplacian pyramids, the `FDGNode` can apply a different guidance scale to each frequency band. This is the "Frequency-Dependent" part of FDG. After guidance is applied to each level, the image is reconstructed from the modified pyramid.

### **3. Detailed Parameter Explanation (`FDGNode.INPUT_TYPES`)**

The `FDGNode` is placed between your model loader and the KSampler in a ComfyUI workflow. It "patches" the model to use the FDG logic instead of the standard CFG logic. Here are its parameters:

#### **`model`**
*   **Type:** `MODEL`
*   **Description:** This is the input diffusion model that you want to patch with FDG.
*   **Practical Use:** You connect the output of your model loader (e.g., "Load Checkpoint") to this input. The `FDGNode` will then output a modified model that you can feed into a KSampler.

#### **`guidance_scale_high`**
*   **Type:** `FLOAT` (default: 7.5, min: 1.0, max: 20.0)
*   **Description:** This parameter controls the guidance strength for the **high-frequency** components of the image. It is analogous to the standard CFG scale, but it primarily affects fine details.
*   **Practical Effect:**
    *   **Higher values:** Result in sharper textures, more defined edges, and more intricate details. If set too high, it can lead to noisy or "crunchy" textures, similar to a very high standard CFG.
    *   **Lower values:** Produce softer, smoother details. If set too low, the image might lack sharpness and fine-grained prompt adherence.

#### **`guidance_scale_low`**
*   **Type:** `FLOAT` (default: 1.0, min: 1.0, max: 20.0)
*   **Description:** This controls the guidance strength for the **low-frequency** components of the image. It affects the overall structure, composition, and large-scale color and lighting of the image.
*   **Practical Effect:**
    *   **Higher values:** The model will more strictly follow the prompt for the overall scene layout and color scheme. This can be useful for ensuring the composition is correct, but high values might make the image feel rigid or "over-baked."
    *   **Lower values:** The model has more creative freedom with the overall composition. This is the main benefit of FDG, as it allows for a low "structural" CFG while maintaining high detail, preventing the washed-out look of a globally low CFG.

#### **`levels`**
*   **Type:** `INT` (default: 2, min: 2, max: 4)
*   **Description:** This determines the number of frequency bands the image is decomposed into. The number of levels in the Laplacian pyramid.
*   **Practical Effect:**
    *   **`levels=2`:** The image is split into high frequencies and low frequencies. `guidance_scale_high` applies to the top level, and `guidance_scale_low` to the bottom.
    *   **`levels=3` or `4`:** The image is split into more frequency bands. The guidance scale is interpolated between `guidance_scale_high` and `guidance_scale_low` for the intermediate levels. This provides a smoother transition in guidance strength from the finest details to the broadest structures. The `interpolation_method` parameter controls how this interpolation happens.

#### **`fdg_steps`**
*   **Type:** `INT` (default: 2, min: 1, max: 50)
*   **Description:** This sets the number of initial sampling steps during which FDG will be active. After this number of steps, the sampler will revert to using the standard CFG scale provided by the KSampler node.
*   **Practical Effect:** The early steps of the diffusion process are where the overall composition and major structures of the image are defined.
    *   **Setting `fdg_steps` to a low value (e.g., 2-5):** You use FDG to establish a strong, detailed foundation for the image in the crucial early steps, then let the standard CFG guide the refinement process.
    *   **Setting `fdg_steps` to the total number of steps:** You use FDG for the entire generation process. This gives you maximum control via the FDG parameters but ignores the KSampler's CFG value.

#### **`interpolation_method`**
*   **Type:** `STRING` (dropdown list, default: "linear")
*   **Description:** This defines the mathematical function used to calculate the guidance scale for the intermediate frequency levels when `levels` is greater than 2.
*   **Practical Effect:** This parameter fine-tunes how the guidance is distributed across the frequency bands.
    *   **`linear`:** A straight-line interpolation. The guidance scale decreases evenly from high to low frequencies. This is a good default.
    *   **`cosine`:** A smooth, curved interpolation. It spends more time at the high and low ends of the scale.
    *   **`exponential`:** The scale changes more rapidly at the beginning (high frequencies) and slows down towards the low frequencies.
    *   **`quadratic_in`/`out`, `cubic_in`/`out`:** These provide different "easing" curves for the interpolation, giving advanced users precise control over which frequency bands receive more or less guidance. For most users, `linear` or `cosine` will be sufficient.

#### **`parallel_weights`**
*   **Type:** `STRING` (default: "1.0,1.0,1.0,1.0")
*   **Description:** This is an advanced parameter that controls the weighting of the "parallel component" of the guidance. It's a list of numbers (one for each level) that modifies how the guidance is applied. In simple terms, it adjusts how much the guidance "aligns" with the direction of the conditional prediction.
*   **Practical Effect:** The `project` function separates the guidance into two parts: one that is parallel to the conditional prediction (i.e., "more of what the model is already doing") and one that is orthogonal to it.
    *   **`1.0` (default):** Standard guidance is applied.
    *   **Values > `1.0`:** Emphasizes the features the model already associates with the prompt, potentially increasing saturation and contrast in that frequency band.
    *   **Values < `1.0`:** De-emphasizes the features the model associates with the prompt, which can be used to subtly reduce artifacts or over-saturation at a specific frequency level.
    *   **Example:** If you find that high frequencies are too "crunchy" even with a reasonable `guidance_scale_high`, you could try setting the first parallel weight to `0.9` or `0.8`.

---

### **4. Internal Helper Functions**

*   **`create_guidance_scales(...)`**: This function takes the high and low guidance scales and the number of levels and generates the list of scales for the pyramid, using the chosen interpolation method.
*   **`project(v0, v1)`**: A mathematical utility that projects one tensor onto another. In `laplacian_guidance`, it's used to decompose the `diff` vector (the difference between the conditional and unconditional predictions) into components that are parallel and orthogonal to the conditional prediction `p_cond`. This allows `parallel_weights` to modify the guidance direction.
*   **`build_image_from_pyramid(...)`**: Reconstructs the final image by collapsing the Laplacian pyramid after guidance has been applied to each level.
*   **`laplacian_guidance(...)`**: This is the core function where the magic happens. It takes the conditional and unconditional predictions, builds pyramids for both, calculates the guided prediction for each level using the provided scales and weights, and then reconstructs the final guided image.
*   **`patch(...)`**: The main method of the `FDGNode`. It takes all the user inputs, prepares the `guidance_scale` and `parallel_weights` lists, and then defines a function (`fdg_function`) that hijacks the model's normal CFG mechanism. This new function is then set on a clone of the model, which is what the node outputs.
